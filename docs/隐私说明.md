\# 隐私说明



\## 我们的承诺

\- 数据不上传：所有数据存于 `data/quiz.db` 或 `%APPDATA%\\\\智卷\\\\quiz.db`

\- 不收集信息：不收集 IP、设备信息、使用行为

\- 不联网也能用：断网状态下所有功能正常运行

\- 删除即销毁：删除 `quiz.db` 文件，所有数据立刻消失



\## 技术细节

\- 后端：Python + Flask（纯本地 HTTP 服务）

\- 数据库：SQLite（单文件）

\- 运行地址：`http://127.0.0.1:5001`（仅本机可访问）

\- 无任何第三方 API 调用、无埋点、无遥测



\## 唯一例外

打包后的 exe 启动时会调用 `webbrowser.open` 打开系统浏览器。

这是本地 API，不涉及网络请求。
